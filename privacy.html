Privacy policy

Last updated: October 11, 2026

Jarvis is a private application used only by its owner, Harsh Pandit, and his household. It is not available to the public.

What it accesses

  • Google Nest (Smart Device Management): the status and settings of the owner's own thermostats, to read and adjust them.
  • Google Drive (read-only): the owner's own files, so he can search them.

How the data is used and stored

  • Data is used only to provide these features to the owner.
  • It is stored on the owner's own computer at home. It is not sold, shared with third parties, or used for advertising.
  • Google user data is handled in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, which stops all further access.
